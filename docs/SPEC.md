# warikan 仕様メモ

飲み会の会計で、幹事が傾斜配分の割り勘をその場で計算するためのアプリ。決まったことはここに 1 行ずつ足していく。

## 想定する使い方

1. 支払金額を入れ、完全均等割だといくらかを目安として見る
2. 先に多めに払って退席した人（上司など）から預かった分を「先払い」として引く
3. 支払い能力が低いグループ（学生など）は 1人あたりの金額を決め打ちする（例: 2,000円）。他のグループの負担が大きすぎたら少し上げて再計算する
4. 残りの人たちはグループごとに傾斜をつけ、納得感のある金額になるまで調整する。傾斜グループの数は飲み会ごとに違う
5. 各グループの 1人あたり額を全員に伝える。集める額は 1,000円・500円単位が望ましい

## 決めたこと

### 計算

- グループの払い方は「傾斜」と「金額固定」の 2 種類
- 傾斜は倍率ではなく **「基準との差額」**（基準より 1人あたり何円多いか。マイナス可）で指定する（v1 の倍率は直感的でなかった）
- 基準額 = (支払金額 − 先払い − 金額固定グループ合計 − Σ 差額×人数) ÷ 傾斜グループ人数。各傾斜グループの額 = 基準額 + 差額 を丸める
- 丸め単位は **1,000 / 500 / 100 円**（左からこの順）。10円・1円単位の額は扱わない
- 端数処理は **切り上げ / 四捨五入** から選ぶ。四捨五入では集金係が少し損をすることがある（クレカのポイント分で吸収する想定）
- 均等割は目安なので丸めない。人数には先払いで退席した人も含める
- 傾斜⇔金額固定を切り替えたときは、今の 1人あたり額が変わらないよう差額・固定額を自動で設定する

### 画面

- 1 画面。上から 支払金額 → 先払い → グループのカード → グループ追加チップ。画面下に丸め単位・端数処理・集金/支払/余り不足を常に表示
- 人数・差額・固定額は ± ボタンで変える（刻みは丸め単位）。キーボードは金額入力のときだけ
- グループはチップ 1 タップでカードを 1 枚追加。同じチップを 2 回押すと「その他 2」のように連番のカードが増える（予想外の属性の人が複数グループいても対応できる）
- カードに名前の入力欄は置かない。見出しをタップすると名前を変えられる（普段は使わない）
- UI は Material 3（Compose）

### グループのプリセット

- チップに並ぶグループは設定画面で事前に作っておく（名前・払い方・初期の金額・並び順）
- 初期値: 役員 15,000円固定 / 部長 10,000円固定 / 課長 +3,000 / 係長 +2,000 / シニア +1,000 / 社員 基準 / 新人 −1,000 / 学生 2,000円固定 / その他 基準
- 基準のグループは変えられる（「このグループを基準にする」で傾斜プリセット全体の差額をずらす）

### 保存

- 前回の入力・丸めの設定・プリセットを端末に保存し、次に開いたときに復元する。リセットボタンで入力だけクリア
