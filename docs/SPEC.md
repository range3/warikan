# warikan 仕様メモ

飲み会の会計で、幹事が傾斜配分の割り勘をその場で計算するためのアプリ。決まったことはここに 1 行ずつ足していく。

## 想定する使い方

1. 支払金額を入れ、完全均等割だといくらかを見る
2. 先に多めに払って退席した人（上司など）から預かった分を「先払い」として引く
3. 支払い能力が低いグループ（学生など）は 1人あたりの金額を決め打ちする（例: 2,000円）。他のグループの負担が大きすぎたら少し上げて再計算する
4. 残りの人たちはグループごとに傾斜をつけ、納得感のある金額になるまで調整する。傾斜グループの数は飲み会ごとに違う
5. 各グループの 1人あたり額を全員に伝える。集める額は 1,000円・500円単位が望ましい

## 決めたこと

- 傾斜は倍率ではなく **「基準より 1人あたり何円多く払うか（上乗せ）」** で指定する（v1 の傾斜倍率は直感的でなかった）
- グループの払い方は「傾斜で分ける」か「金額を決める（固定）」の 2 種類
- 計算: 傾斜グループの基準額 = (支払金額 − 先払い − 固定グループ合計 − Σ 上乗せ×人数) ÷ 傾斜グループ人数。各グループの額 = 基準額 + 上乗せ を丸め単位で **切り上げ**
- 丸め単位は 丸めない / 100 / 500 / 1,000 円から選ぶ。画面下部に集金合計・支払金額・余り/不足を常に表示する
- 均等割の人数には先払いで退席した人も含める
- 人数・上乗せ・固定額はキーボードを使わず ± ボタンで変える。上乗せと固定額の刻みは丸め単位に合わせる（100〜500円）
- グループは「上司 / 社会人 / 学生 / その他」のチップから 1 タップで追加できる
- UI は Material 3（Compose）
