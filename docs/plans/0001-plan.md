**Status:** Draft

## 1. プロダクト概要

飲み会の幹事や突発的な飲み会開催時に、**傾斜配分付きで各人の支払い金額を計算する** スマホファーストの静的 Web アプリ。

- **想定シーン:** 飲み会会場（屋内・暗所）で幹事が片手・数十秒で入力 → その場で各人に金額を伝える
- **デプロイ:** GitHub Pages（静的、サーバなし）
- **スタック:** Vite + React 19 + TypeScript + Tailwind CSS v4（[ADR-0003], [ADR-0004], [ADR-0005] 準拠）

---

## 2. 機能要件（MVP）

### コア入力

| 入力項目 | 仕様 |
|---------|------|
| 合計金額 | 数値（円） |
| グループ | 名前・人数・配分モード（傾斜 or 固定額）。複数同時に共存可能 |
| 傾斜 weight | 0.1 刻みステッパー、下限 0.1、上限なし |
| 固定額 | グループ単位で「1人あたり N円」を入力 |
| 預り金 | グループに「前払い金額」「先に退出する人数」を任意で設定可能 |
| 丸め単位 | 1 / 100 / 500 / 1000 円の 4 通りを **常に並列表示**（切替トグル不要） |

**個人名は扱わない**（グループ名 + 人数のみで管理し、UI を軽くする）。

### 出力

- 各グループの「1人あたり支払額」を丸め単位ごとに表示
- **幹事差額**（実集金額 − 合計金額）を各カードで表示。正なら緑（得）、負なら赤（損）
- 現在の入力状態を表す URL（コピー可能）

### 永続化

- **localStorage**: 最後の入力状態 + カスタムプリセット
- **URL fragment**: `#state=<URL-safe Base64>` で現在状態をエンコード。共有・復元用
- **起動時の優先順位:** URL fragment > localStorage > デフォルトプリセット

### プリセット

- **デフォルト:** 「上司 / 社会人 / 社会人学生 / 学生」を人数 0 で初期表示
- **カスタム:** 幹事リピート利用向けに、自分の常連グループ構成を localStorage に保存可能

### 操作

- **URL コピー:** 固定下部 Action Bar から 1 タップ
- **リセット:** 全入力クリア（破壊的、要確認 or Undo は実装段階で判断）

## 3. 計算ロジック

1. `実合計 = 合計金額 − Σ (各グループの預り金額)`
2. `実人数 = Σ (各グループの count)`
   ※ `count` は「配分対象人数」であり、先に退出する人は最初から含めない（=ユーザーが count を 1 減らして入力する想定）
3. **固定額グループ** の `1人あたり × count` を `実合計` から先に引く
4. 残額を **傾斜グループ** の `weight × count` で按分し、1人あたり金額を算出
5. 1 / 100 / 500 / 1000 円単位それぞれで **切り上げ** 丸め（飲み会慣例：幹事は得 or トントン）
6. `幹事差額 = 丸め後の集金合計 − 合計金額` を表示

**判断保留:** グループごとに丸め方向を変えるか（現状は全体一律切り上げで進める）。

## 4. データモデル

```ts
type Group = {
  id: string;
  name: string;              // "上司", "社会人", etc.
  count: number;             // 配分対象人数（退出者は含まない）
  mode: "weight" | "fixed";
  weight?: number;           // mode = "weight" の時のみ、0.1 刻み, 下限 0.1
  fixedAmount?: number;      // mode = "fixed" の時のみ、1人あたり円
  prepaid?: {
    amount: number;          // グループ内の先払い合計
    count: number;           // 先に退出した人数（記録目的、計算には未使用）
  };
};

type CustomPreset = {
  id: string;
  name: string;
  groups: Omit<Group, "id">[];
};

type Bill = {
  total: number;
  groups: Group[];
};

type AppState = {
  bill: Bill;
  presets: CustomPreset[];   // localStorage のみ。URL には乗せない
};
```

URL fragment には `bill` のみエンコード（presets は端末固有）。

## 5. デザイン方針

**詳細は `design-system/warikan/MASTER.md` を Source of Truth とする。** 以下はサマリ。

| 項目 | 方針 |
|-----|------|
| スタイル | Flat Design + Touch-First（装飾シャドウなし、border ベース） |
| カラー | Primary 緑（集金・正）、Destructive 赤（削除・損益マイナス）。色だけで意味を伝えない |
| ダークモード | first-class（`prefers-color-scheme` で全 token ペア定義） |
| タイポ | Inter（`@fontsource-variable/inter` で同梱、CDN 不使用）。数値は全て `tabular-nums` |
| アイコン | `lucide-react` のみ。絵文字不使用 |
| レイアウト | `max-w-md` 中央 1 カラム、mobile-first、下部固定 Action Bar（safe-area 対応） |
| ページパターン | Input → Result の縦 1 スクロール 1 画面完結 |

**ビジュアル確認済み:** `design-system/warikan/mockup.html`（単一 HTML、light/dark 両モード検証済み）
